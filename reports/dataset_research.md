# RealTrace AI — Dataset Research

## Project Dataset Requirements

RealTrace AI requires datasets containing:

- Real/camera-captured images
- AI-generated images
- Multiple generation sources
- GAN-based generators where available
- Diffusion-based generators where available
- Generator/source metadata where available

## Required Experimental Capabilities

The final dataset design should support:

1. Standard train/validation/test evaluation
2. Cross-generator evaluation
3. Held-out generator evaluation
4. Unseen-generator evaluation
5. Robustness testing
6. Frequency-domain/forensic analysis
